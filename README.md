# 🍕 Zomato Restaurant Data Analysis

## Internspark Data Science Internship - Task 1

### 📊 Project Overview
Analyzed restaurant data to understand what makes restaurants successful.

### 🔍 Key Findings
- Average restaurant rating: 3.8/5
- Most popular cuisine: North Indian
- Best location: Connaught Place
- Price range ₹500-1500 gets best ratings

### 📈 Visualizations Created
1. Rating distribution histogram
2. Top 5 cuisines bar chart
3. Price vs rating scatter plot
4. Top locations horizontal bar chart

### 💡 5 Recommendations for Internspark
1. Partner with North Indian restaurants
2. Focus marketing on Connaught Place area
3. Promote restaurants in ₹500-1500 price range
4. Add "Top Rated Near Me" feature
5. Create cuisine comparison guides

### 🛠️ Tools Used
- Python 3
- Pandas (data cleaning)
- Matplotlib (visualizations)
- Google Colab
